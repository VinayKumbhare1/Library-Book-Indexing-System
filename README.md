# Library Book Indexing System Using Hash Tables

## Project Description

The Library Book Indexing System is a Python-based project
that uses a hash table to store and manage library books
using ISBN numbers.

## Features

- Add Book
- Search Book
- Delete Book
- Update Book
- Display All Books
- Collision Handling
- Input Validation

## Data Structure

Hash Table

## Collision Handling

Separate Chaining is used to handle collisions.

Example:

101 % 10 = 1
111 % 10 = 1

Both books are stored at index 1.

## Technology Used

- Python
- Hash Table
- Separate Chaining
- Git
- GitHub

## How to Run

python main.py
